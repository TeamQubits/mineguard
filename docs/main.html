MPU6050

3-AXIS ACCELEROMETER / GYROSCOPE

Monitors strata inclination, borehole rotational deviation, and tilt angles (Pitch & Roll). Detects bed separation and ground shifting long before surface cracks appear.

Flex Bend Sensor

HIGH-ELASTICITY RESISTIVE STRIP

Embedded inside the probe’s flexible core tube across lithological strata boundaries. Measures lateral shear displacement, borehole buckling, and horizontal bed slip.

Data Flow & Safety Execution

End-to-End System Pipeline

01

Borehole Sensing

MPU6050, Flex, and Moisture sensors detect subterranean shifts, bedding separation, and pore pressure changes within borehole strata.

02

STM32 Edge Compute

Sensor fusion running on STM32 validates true deformation events versus micro-seismic noise. Encodes payload into compact binary packets.

03

LoRa Long-Range Link

Packets transmitted across the surface perimeter to the mine central gateway, bypassing underground obstacles without cellular reliance.

04

Early Warning & Cloud

Cloud GIS dashboards plot 3D surface subsidence heatmaps. Triggers audio-visual alarm sirens to evacuate danger zones before catastrophic caving.
